# Internshala PGC SQL Project

This repository contains SQL scripts and database work completed as part of the Internshala Placement Guarantee Course (PGC). The project focuses on building strong fundamentals in SQL and practical database management.

## Repository Contents

- database.sql  
  SQL script used to create the database schema and tables.

- project.sql  
  SQL queries and operations demonstrating practical SQL use cases.

- README.md  
  Project documentation.

## Project Overview

This project showcases hands-on experience with SQL concepts learned during the Internshala PGC program. It includes database creation, data manipulation, and query-based problem solving using structured query language.

Key concepts covered include:
- Database and table creation
- Data insertion and updates
- Writing SELECT queries
- Using JOINs, WHERE clauses, GROUP BY, and ORDER BY
- Solving real-world SQL problems

## Tools and Technologies

- SQL
- MySQL / PostgreSQL / SQLite (any SQL-supported database)
- DB Browser / MySQL Workbench / pgAdmin

## Setup Instructions

1. Clone the repository:
   git clone https://github.com/AbelAliasAbraham/Internshala-PGC-SQL.git

2. Open your preferred SQL database tool.

3. Run the database.sql file to create the database and tables.

4. Execute the project.sql file to practice and analyze SQL queries.

## Learning Outcomes

- Strong understanding of SQL fundamentals
- Practical experience with database design
- Ability to write efficient and structured SQL queries
- Hands-on exposure to real-world database scenarios
